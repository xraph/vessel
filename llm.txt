# vessel

Dependency injection container for Go. Module: github.com/xraph/vessel (Go 1.25+).
Used by the Forge framework, usable on its own. Interfaces and registration options
come from github.com/xraph/go-utils/di, so most code imports both packages.

## Mental model

One container, two independent registries:

1. Type registry (dig style, preferred). Register constructors with Provide*, resolve
   with Inject*. Parameters are dependencies, results are provided services.
2. Name registry. Register factories with c.Register(name, factory, opts...), resolve
   with c.Resolve(name) and type-assert. Supports declared dependencies for start
   ordering, request scopes, Lazy/Provider wrappers and middleware.

The registries do not see each other: a constructor cannot receive a service that was
registered with Register, and Resolve(name) cannot find a Provide'd service. Inject*
works from inside a Register factory (pass it the factory's container).

## Core types

    type Vessel = di.Container   // the container interface
    type Scope = di.Scope        // Resolve(name) (any, error); End() error
    type Factory = di.Factory    // func(c di.Container) (any, error)
    type ServiceInfo = di.ServiceInfo
    type RegisterOption = di.RegisterOption

    func New() Vessel

di.Container methods:

    Register(name string, factory Factory, opts ...RegisterOption) error
    Resolve(name string) (any, error)
    ResolveReady(ctx context.Context, name string) (any, error) // start first, ctx passed to Start
    Has(name string) bool
    IsStarted(name string) bool
    Services() []string            // sorted; named services + health-capable typed services
    BeginScope() Scope
    Start(ctx context.Context) error
    Stop(ctx context.Context) error
    Health(ctx context.Context) error
    Inspect(name string) ServiceInfo

Lifecycle interfaces (package di), detected on built instances:

    di.Starter       Start(ctx) error   // called on first build of a singleton, or by Start
    di.Stopper       Stop(ctx) error    // called by Stop
    di.HealthChecker Health(ctx) error  // called by Health and Inspect
    di.Disposable    Dispose() error    // called by Scope.End for scoped instances

## Type registry API

    func Provide(c Vessel, constructor any, opts ...ConstructorOption) error
    func ProvideNamed(c Vessel, name string, constructor any, opts ...ConstructorOption) error
    func ProvideValue[T any](c Vessel, value T, opts ...ConstructorOption) error

    func Inject[T any](c Vessel) (T, error)
    func InjectNamed[T any](c Vessel, name string) (T, error)
    func InjectGroup[T any](c Vessel, group string) ([]T, error) // nil, nil for empty group
    func InjectScoped[T any](s Scope) (T, error)
    func InjectScopedNamed[T any](s Scope, name string) (T, error)
    func MustInject[T any](c Vessel) T                 // Must* panic on error
    func MustInjectNamed[T any](c Vessel, name string) T
    func MustInjectGroup[T any](c Vessel, group string) []T
    func MustInjectScoped[T any](s Scope) T
    func HasType[T any](c Vessel) bool
    func HasTypeNamed[T any](c Vessel, name string) bool

    // Deprecated aliases: ProvideConstructor = Provide, InjectType = Inject,
    // MustInjectType = MustInject.

ConstructorOption:

    WithName(name)          register under (type, name); resolve with InjectNamed
    WithAliases(names...)   extra names for the same registration and instance
    As(new(Iface), ...)     also register under interface types; same instance;
                            Provide errors if the result doesn't implement them
    AsGroup(group)          add to a value group (InjectGroup or `group:"..."` field)
    AsSingleton()           default: one instance per container, built on first use
    AsTransient()           new instance per resolve
    AsScoped()              one instance per scope; resolve with InjectScoped
    WithEager()             build immediately inside Provide and return its error
                            (ignored for AsScoped)

Constructor rules:

- Any func. Each parameter is resolved by type (unnamed key). Results except a final
  `error` are registered. Only the `error` interface itself counts as the error result.
- Provide(c, nil) or a nil func returns an error.
- Several results (`func() (*A, *B, error)`) or an Out struct: the constructor runs once
  per lifetime and all results share that call.
- Registration is atomic. If any key (type+name, alias, As type) is taken, nothing is
  registered and the error has code SERVICE_ALREADY_EXISTS.
- ProvideValue registers under the type parameter. To register under an interface, pass
  it explicitly: vessel.ProvideValue[Store](c, &fakeStore{}).
- Each group member needs a unique (type, name), so name members of the same type.

Parameter and result structs:

    type Params struct {
        vessel.In
        DB       *Database
        Cache    *Cache    `name:"redis"`      // InjectNamed[*Cache](c, "redis")
        Logger   *Logger   `optional:"true"`   // zero value if not registered
        Handlers []Handler `group:"routes"`    // must be a slice
    }

    type Results struct {
        vessel.Out
        Users  *UserRepo
        Orders *OrderRepo `name:"orders"`   // `group:"..."` also supported
    }

Only exported fields are used. `optional` covers a missing provider only; if a provider
exists and fails, the error is returned.

## Name registry API

Registration options (package di), combinable:

    di.Singleton()                   default
    di.Transient()
    di.Scoped()
    di.WithDependencies("a", "b")    declared eager deps, for Start ordering only
    di.WithDeps(di.Eager("a"), di.Lazy("b"), di.Optional("c"), di.LazyOptional("d"))
    di.EagerTyped[T](name), di.LazyTyped[T](name), di.OptionalTyped[T](name), ...
    di.WithGroup("storage")          for Query/FindByGroup
    di.WithDIMetadata("k", "v")      for Query metadata filters

Declared dependencies do not inject anything; the factory resolves what it needs from
the container it is given. Start sorts by declared eager dependencies (lazy ones are
ignored, so di.Lazy can break a declared cycle) and fails on a declared cycle.

Wrappers over named services:

    func NewLazy[T any](c di.Container, name string) *Lazy[T]
        Get() (T, error); MustGet() T; IsResolved() bool; Name() string
        Resolves once; caches the value or the first error.
    func NewOptionalLazy[T any](c di.Container, name string) *OptionalLazy[T]
        Get returns zero value and nil error if name is not registered; IsFound() bool.
    func NewProvider[T any](c di.Container, name string) *Provider[T]
        Provide() (T, error); MustProvide() T. Resolves on every call.

## Scopes

    scope := c.BeginScope()
    defer scope.End()
    v, err := scope.Resolve("request")              // named
    s, err := vessel.InjectScoped[*Session](scope)  // typed

- Scoped: one instance per scope. Singleton: from the container. Transient: new.
- Resolving a scoped service from the container (Resolve or Inject) is an error.
- Factories and constructors running in a scope get a scope-bound container, so scoped
  services can depend on other scoped services in the same scope.
- A singleton cannot depend on a scoped service; building it returns an error.
- End disposes di.Disposable instances newest first, returns errors joined (errors.Is
  works), and later resolves return ErrScopeEnded. End twice returns ErrScopeEnded.
- Per-scope values, via the concrete type:
      store := scope.(interface{ Set(string, any); Get(string) (any, bool) })

## Lifecycle semantics

- Singletons implementing di.Starter start on first resolve (Resolve or Inject), with
  the caller's context where one exists (ResolveReady, Start) else context.Background.
- Transient instances are started when built and never stopped.
- Scoped instances are not started; they are disposed by Scope.End.
- Start(ctx): builds and starts every named singleton in declared dependency order,
  then starts typed singletons that are already built. Unbuilt typed singletons stay
  lazy. On failure, stops everything started so far, then returns. Idempotent.
- Stop(ctx): stops every started singleton from both registries in reverse actual start
  order, including ones auto-started without Start. Continues past failures and returns
  them joined. Marks services stopped even without a Stop method. Start can run again.
- Health(ctx): checks built singletons implementing di.HealthChecker; first error wins.
- Inspect(name) and the query helpers call Health on built services to fill Healthy.
- Concurrent first resolution of a singleton builds it once; other callers wait.
- Resolution cycles (a resolves b resolves a) return a CIRCULAR_DEPENDENCY error with
  the path, e.g. "a -> b -> a". Detection follows the container passed to the factory,
  so factories must resolve through their own argument, not a captured outer container.

## Middleware

    type Middleware interface {
        BeforeResolve(ctx, name string) error
        AfterResolve(ctx, name string, service any, err error) error
        BeforeStart(ctx, name string) error
        AfterStart(ctx, name string, err error) error
    }
    type FuncMiddleware struct { BeforeResolveFunc, AfterResolveFunc, BeforeStartFunc, AfterStartFunc }

    c.(interface{ Use(vessel.Middleware) }).Use(mw)   // Use is not on the Vessel interface

Runs in the order added, for every named resolve (including through scopes) and every
named auto-start. Any hook returning an error aborts the operation. Not run for Inject.

## Querying

    type ServiceQuery struct {
        Lifecycle string            // "singleton" | "transient" | "scoped"; "" = any
        Group     string
        Metadata  map[string]string // all must match
        Started   *bool
    }
    func Query(c Vessel, q ServiceQuery) []ServiceInfo
    func QueryNames(c Vessel, q ServiceQuery) []string
    func FindByGroup(c Vessel, group string) []ServiceInfo
    func FindByLifecycle(c Vessel, lifecycle string) []ServiceInfo
    func FindStarted(c Vessel) []ServiceInfo
    func FindNotStarted(c Vessel) []ServiceInfo

ServiceInfo: Name, Type, Lifecycle, Dependencies, Deps, Started, Healthy, Metadata.
Groups are exposed in Metadata["__groups"], comma-separated.

## Errors

Errors are *errs.Error from go-utils; errors.Is matches by code.

    ErrServiceNotFoundSentinel     SERVICE_NOT_FOUND     Resolve, Inject, constructor params
    ErrCircularDependencySentinel  CIRCULAR_DEPENDENCY   Start, Resolve, Inject
    ErrInvalidFactory              INVALID_FACTORY       Register with nil factory
    ErrScopeEnded                  SCOPE_ENDED           use of an ended scope
    ErrTypeMismatchSentinel        TYPE_MISMATCH
    (code) SERVICE_ALREADY_EXISTS  duplicate Register name or typed key
    (code) SERVICE_ERROR           wraps factory/start/stop/health failures; Unwrap works

Constructors: ErrServiceNotFound(name), ErrServiceAlreadyExists(name),
ErrCircularDependency(cycle), ErrTypeMismatch(name, actual), NewServiceError(name, op, cause).

## Examples

Constructor injection:

    c := vessel.New()
    vessel.ProvideValue(c, &Config{DSN: "postgres://localhost/app"})
    vessel.Provide(c, NewDatabase)      // func(*Config) (*Database, error)
    vessel.Provide(c, NewUserService)   // func(*Database) *UserService
    if err := c.Start(ctx); err != nil { return err }
    defer c.Stop(ctx)
    users, err := vessel.Inject[*UserService](c)

Named services with start ordering:

    c.Register("config", func(c vessel.Vessel) (any, error) { return LoadConfig() })
    c.Register("database", func(c vessel.Vessel) (any, error) {
        cfg, err := c.Resolve("config")
        if err != nil { return nil, err }
        return NewDatabase(cfg.(*Config))
    }, di.WithDependencies("config"))

Per-request scope:

    c.Register("request", newRequestCtx, di.Scoped())
    scope := c.BeginScope()
    defer scope.End()
    rc, err := scope.Resolve("request")

Test fake:

    c := vessel.New()
    vessel.ProvideValue[PaymentGateway](c, &fakeGateway{})
    vessel.Provide(c, NewCheckout)
    checkout := vessel.MustInject[*Checkout](c)

## Gotchas

- Provide/Inject and Register/Resolve are separate registries.
- Resolve returns any; type-assert the result.
- Registration options are in go-utils/di, not vessel.
- Use (middleware) and scope Set/Get need type assertions.
- Lazy caches a failed resolution permanently.
- Inspect and Query trigger Health checks.
- Typed services appear in Services()/Query only if they implement di.HealthChecker.
